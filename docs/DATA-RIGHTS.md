# 代码许可与研究资料边界

本仓库是独立开发的本地检索软件，并非 CHARLS 或 Gateway to Global Aging Data 的官方产品。

## 公开内容

公开原创软件源码、配置模板、人工整理的检索词、合成测试和原创使用说明。软件继续使用仓库中的 MIT License，并保留原版权声明。依赖仅声明名称和版本，不把依赖源码或安装包打包进仓库；使用和再分发依赖时仍须遵守各自许可。

## 本地内容

CHARLS 微观数据、压缩包、官方 Stata 程序、codebook、问卷、流程图、提取全文、原始变量字典及构建后的 SQLite 索引均不随仓库发布。即使索引没有受试者观测行，也不能据此把其文档文本或标签集合视为本项目的 MIT 内容。

MIT License 仅授权本项目的软件与原创说明，不授予第三方研究资料的使用或再分发权。获取研究资料的用户须自行遵守官方数据使用协议及来源机构的要求。本仓库不会提供凭据、登录 Cookie 或绕过申请流程的下载方式。

## 来源与引用

- [CHARLS 官方数据入口](https://charls.charlsdata.com/)：由用户自行获取其有权使用的研究资料。
- [CHARLS 官方常见问题](https://charls.pku.edu.cn/Faq/cjwt.htm)：说明数据申请、数据使用协议和结合问卷核对标签的要求。
- [CHARLS Wave 4 官方用户指南](https://charls.pku.edu.cn/en/data/User2018.pdf)：提供按数据用途引用调查、体检、血样和追踪资料的说明。
- [Harmonized CHARLS 官方说明](https://charls.pku.edu.cn/en/Data/Harmonized_CHARLS.htm)：Harmonized 产品的来源入口；还应核对实际版本文档中的引用要求。

仓库只保存来源链接、校验方法及必要的版本信息，不镜像上述资料。研究发表时请引用实际使用的数据与文档来源，不能用本软件的引用替代数据引用。

## 发布检查

`.gitignore` 排除数据目录、报告、PDF、数据库、压缩包、Word 文档、本机配置与备份。该规则不能阻止已经跟踪或被强制添加的文件；每次发布前仍须检查完整 Git 文件清单和差异，禁止提交真实数据、全文索引、原始标签导出、账号信息及协议抓取。

公开软件测试使用合成资料；真实文档验收的期望文件、页码索引及原文锚点全部留在本地私有目录；公开代码从外部加载这些文件，不内嵌真实 gold。连接真实本地资料的验证脚本可公开，脚本生成的结果、路径和捕获内容留在本地。
